# StudySpace 📚

StudySpace is a simple and responsive educational website designed to help students develop better study habits, organise their learning, and make their study time more effective.

The website provides practical study tips, useful learning resources, and simple guidance for students who want to create a more organised approach to learning.

## 🎯 Purpose

The goal of StudySpace is to provide students with straightforward information that can help them:

* Set clear study goals
* Reduce distractions
* Take useful study breaks
* Organise their learning
* Find reliable educational resources
* Build better study habits

## 📖 Website Sections

### Home

Introduces StudySpace and explains what the website is about.

### Study Tips

Provides practical advice for improving study routines, including setting goals, removing distractions, and taking useful breaks.

### Resources

Highlights useful learning resources, including external educational websites such as MDN Web Docs.

### About

Explains the idea behind StudySpace and its focus on making learning simpler and more organised.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Responsive Web Design
* CSS Grid
* CSS Flexbox

No JavaScript or backend is required for this project.

## 📱 Responsive Design

StudySpace is designed to work across different screen sizes, including:

* Desktop computers
* Tablets
* Mobile phones

CSS media queries are used to adjust the layout, navigation, text, cards, and images for smaller screens.

## ♿ Accessibility

The website uses semantic HTML and descriptive alternative text for images to make the content easier to understand and navigate.

## 🚀 Project Goal

This project was created as a beginner web development project to practise building a complete website using HTML and CSS while focusing on structure, visual design, navigation, accessibility, and responsive layouts.
